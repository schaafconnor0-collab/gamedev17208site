Overview

About the Program

Purdue is tailored and specialized for the cultivation of necessary skills that Game Programmers should have when entering the field helping them understand the history, evolution, psychology, and methods for Game Development that will give them the upper hand and a better head start opposed to other programmers. Our teachers who run this program are carefully picked through their experience and fondness of this field and want to help you as a potential Game Programmer/Designer excel in your field.

Our courses do not stop at just game programming and design, it branches out to web design, digital art, data visualization, and many others. Students will have the option to specialize in one of these fields that can and will be connected to Game Development. Curriculum

What You’ll Learn

Students will learn many skills which are not limited to

  • Programming Languages such as Java, C++, JavaScript, etc.
  • The basics of art/studio designs like perspective, depth, focus, etc.
  • Web Development skill such as CSS and Html
  • Basics of Data Visualization, learning the graph types and when to use certain types
  • Modeling in different studios and programs used throughout the courses.
